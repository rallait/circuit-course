# 电路基础交互式课件

面向汽车维修与电气爱好者的**纯前端交互式教学课件**。所有内容打包在单文件 HTML 里，双击即可在浏览器运行，无需任何服务器、安装包或网络连接。

## 文件一览

| 文件 | 大小 | 内容 |
|------|------|------|
| `直流电路基础-交互式课件.html` | ~775 KB | 电路工坊、欧姆定律、基尔霍夫、戴维南/诺顿、Y-Δ 变换、电源内阻、网孔/节点法、暂态、万用表训练、安全、故障诊断等 **20 个视图** |
| `交流电基础-交互式课件.html` | ~229 KB | 正弦波基础、相量、RLC 串联/并联、谐振、功率因数、三相电等内容 |

## 如何使用

1. 下载仓库（Clone / Download ZIP）
2. 双击任意一个 `.html` 文件，Chrome / Edge / Firefox / Safari 打开
3. 左侧点击导航栏切换视图，右侧滑动交互元件参数，观察画布实时变化和数值同步

## 设计特点

- **零依赖**：纯 HTML5 + Canvas 2D + 原生 JS，不引入任何外链资源
- **数据驱动**：每个视图内部维护一个状态对象（如 `var THEV = {...}`），滑杆 / 按钮 → `xxxSync()` → 重绘
- **汽车场景贯穿**：电瓶 Uoc / R0、起动机线圈、大灯电阻、继电器触点、整车搭铁短路故障诊断
- **离线讲义**：每个交互模块自带可折叠的 `<details class="lsn">` 讲义块，公式、推导、真实参数都在页面里

## 技术栈

- HTML5 `canvas` 元素 + 2D 绘图 API
- 原生 JavaScript（`'use strict'` IIFE 作用域）
- 无框架、无构建步骤
